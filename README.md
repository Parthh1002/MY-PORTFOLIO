## ✨ About The Project
This repository contains the source code for my **Personal Portfolio Website**, designed and developed to showcase my projects, hackathon achievements, and technical expertise.

Built with an extreme focus on **Premium UI/UX**, butter-smooth 60–120 FPS performance, low-latency micro-interactions, responsive design across all devices, and obsidian dark-glassmorphism aesthetics. It represents my journey as a **Full-Stack Developer** and **AI/ML Engineer**.

## 🚀 Key Highlights & Features
- **Cinematic Entrance Animation**: Custom Netflix-style PP monogram slam and letter reveal with Framer Motion.
- **Ultra-Smooth Performance**: Hardware-accelerated canvas particle field optimized for both low-end mobile devices and high-end desktops.
- **Zero-Cost Off-Thread ScrollSpy**: Powered by native `IntersectionObserver` for stutter-free scrolling.
- **Full Case Study Modals**: Deep dives into architecture, technical stack, live links, and features for each project.
- **Interactive Tech Stack Grid**: Floating tech tiles with category tooltips and spring physics.
- **Dynamic Palette Switcher**: Real-time accent color customizer with Sapphire, Emerald, Amethyst, Crimson, and Amber hues.
- **In-App Interactive CV**: Instant PDF preview modal with direct download options.

## 🛠️ Installation & Setup

Want to run this portfolio locally?

```bash
# 1. Clone the repository
git clone https://github.com/Parthh1002/MY-PORTFOLIO.git

# 2. Navigate into the frontend directory
cd "MY PORTFOLIO/frontend"

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
