## ✨ About The Project
This repository contains the source code for my **Personal Portfolio Website**, designed and developed to showcase my projects, hackathon achievements, and technical skills. 

Built with an extreme focus on **Premium UI/UX**, smooth micro-interactions, responsive design, and glassmorphism aesthetics. It represents my journey as a **Fullstack Developer** and **DBMS Enthusiast**.

## 🚀 Features
- **Cinematic Entrance Animation**: Uses GSAP and Framer Motion for a stunning first impression.
- **Interactive Tech Stack Grid**: A dynamic floating grid of technology icons with tooltips.
- **Glassmorphic Design**: Clean and modern semi-transparent UI elements that adapt beautifully to different viewports.
- **Seamless Responsiveness**: Perfect layouts from 4K desktop screens down to the smallest mobile devices.
- **Interactive Particles Background**: A custom animated starfield/particle background.
- **Dynamic Theme Toggling**: Integrated support for viewing the site in the best lighting.

## 🛠️ Installation & Setup

Want to run this portfolio locally? It's super easy!

```bash
# 1. Clone the repository
git clone https://github.com/Parthh1002/MY-PORTFOLIO.git

# 2. Navigate into the frontend directory
cd frontend

# 3. Install the dependencies
npm install

# 4. Start the development server
npm run dev
```
